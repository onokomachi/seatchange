# 席替えあぷり

どのクラスでも使える席替えアプリです。名簿と座席の形を自分で設定して使います。
名簿などのデータは、使っているパソコンのブラウザの中だけに保存され、外部には送信されません。

## はじめに（クラス設定）

初めて開くと「クラス設定」が表示されます。あとから右上の「クラス設定」ボタンでいつでも変更できます。

1. **① 名簿**
   - 人数（出席番号の上限）を入力し、名前・ふりがな・男女を入力します（名前を空欄にすると「○番」と表示）。
   - Excel などからコピーした名簿を、まとめて貼り付けることもできます。
   - **国・算で抜ける**: 特別支援学級で国語・算数の授業に抜ける児童にチェックすると、「国・算ver」で後ろの席にまとめて固定されます。
   - **前の席**: 視力・配慮などで前の席にしたい児童にチェックします。
2. **② 座席の形**
   - 横（列）と縦（行）のマス目の数を決め、マスをクリックして席を置く・消すができます（通路や、後ろに1つだけ突き出た席なども作れます）。
   - 「男女を切り替える」で、席ごとに男子席・女子席を指定できます（縦じま・市松模様の一括設定あり）。
   - 「前の席」とみなす範囲（前から何列目まで）と、国・算verで後ろに固める位置（左寄せ・中央・右寄せ）もここで決めます。
3. **③ 配慮**
   - **隣にしない組み合わせ** と **隣にしたい組み合わせ** を登録します（隣＝前後左右）。
4. **保存・読込**
   - 設定・座席表・記録を1つのファイルに書き出したり、読み込んだりできます（別のパソコンへの移動やバックアップに）。

## 主な機能

- 席順のシャッフル（男女固定席）／男女ランダム
- 全員ver／国・算ver（抜ける児童を後ろに固定）
- 児童視点（黒板が上）／教師視点（黒板が下）の切り替え
- 席を2つ順にクリックして手動で入れ替え（空席への移動も可）
- 同じ席を2回押して欠席に設定（シャッフル時に後方へまとめ、在席者を前に詰める）
- 「この席を記録」で、次回から同じ席をなるべく避ける
- 名前を付けて履歴に保存・復元
- 印刷・PDF書き出し

## 開発者向け：ローカルで動かす

**必要なもの:** Node.js

1. `npm install`
2. `npm run dev`
